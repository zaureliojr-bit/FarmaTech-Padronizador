# 🏥 FarmaTech Padronizador

Sistema para padronização automática de produtos farmacêuticos através do código EAN.

## Objetivo

Importar uma planilha, consultar um banco local, pesquisar produtos inexistentes, padronizar informações e exportar uma nova planilha.

---

## Tecnologias

- React
- Node.js
- SQLite
- XLSX
- GitHub

---

## Fluxo

Importar XLSX

↓

Ler EAN

↓

Consultar Banco

↓

↓
